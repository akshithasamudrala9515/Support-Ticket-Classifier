# Support Ticket Category Classifier

## Project Overview

This project uses Natural Language Processing (NLP) and Machine Learning to classify customer support tickets into different categories and predict urgency levels.

## Features

- Customer ticket classification
- Urgency prediction (High / Medium / Low)
- TF-IDF text feature extraction
- Logistic Regression machine learning model
- Streamlit web application

## Ticket Categories

The model predicts:

- Billing inquiry
- Cancellation request
- Product inquiry
- Refund request
- Technical issue

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Streamlit

## Model Performance

Accuracy: 85.46%

F1 Score: 85.51%
